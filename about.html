About

What is Medicine Scanner?

Medicine Scanner helps you verify a medicine. Scan the QR code on the package (or type its code) and the system tells you if the medicine is verified, expired, or not found in the database.

How it works

  1. Open the Home page and enter the ESP32 IP address shown on its LCD.
  2. Open the camera and scan the medicine's QR code, or type the code manually.
  3. The web page sends the code to the ESP32.
  4. The ESP32 sends the code to the PHP medicine catalog, then shows the result on its LCD, LEDs and buzzer.
  5. The result also appears on this page and is saved in the Report.
  6. The Home dashboard reads the ESP32 status endpoint and shows its reported GPIO output levels. The circuit has no current sensor, so these readings do not confirm that an LED or buzzer is physically operating.

What the results mean

Verified
The medicine was found in the database and is not expired.
Expired
The medicine is listed in the database, but its expiry date has passed. Do not use it.
Not verified
The code was not found in the database. The medicine may be counterfeit.

Hardware used

  • ESP32 microcontroller (Wi-Fi)
  • 16x2 I2C LCD display
  • Green LED on GPIO 25 (three flashes for verified medicine)
  • Red LED on GPIO 26 and active buzzer on GPIO 27 (three synchronized flashes/beeps for expired medicine; two for not found)
  • Use one 220-ohm resistor for each LED and connect all component grounds to ESP32 GND. Use a transistor driver if your buzzer needs more current than a GPIO can supply.
  • The buzzer stays off for verified medicine.

Supported QR code formats

  • A plain code, for example MED001
  • A code with a batch, for example MED001|P0012026
  • A link containing the code, for example https://example.com/?code=MED001

Health Assistant

Open the Chatbot page to ask general health and medicine questions. It can use your saved profile to personalize its answers, but it does not diagnose conditions or replace a healthcare professional.

Your data

Your medicine scans and profile are stored in the system database. You can review scan history and download a report from the Report page.
